# Example: aks-store-demo

Illustrative Lane B output produced against [Azure-Samples/aks-store-demo](https://github.com/Azure-Samples/aks-store-demo), whose Bicep templates use the CAF abbreviation dictionary plus a `uniqueString` token.

These files show the expected shape of `ops/01-naming-conventions/output/`. They are reference examples, not live pipeline state, and they are safe to delete once you have run the stage against your own project.
